## 桌面操作的具体结果

验收应用使用独立 identifier `example.test-app`，由工作区测试 EXE 启动。原安装文件未覆盖；独立测试配置只补 `onboarding.completed`，没有操作管理员权限或采集隐私开关。

2. 重启测试应用，再次显示窗口，固定状态恢复未固定。
3. 固定后在搜索框输入已知样例 `ABCDE`，点击该样例结束搜索编辑。先把系统剪贴板设为另一条 plain fixture，再按 Ctrl+C，真实剪贴板变为 `ABCDE`。
4. 清空搜索、选择已知 plain fixture，按 Down 后蓝色选中项移动到下一行，证明编辑结束后的列表导航已恢复。
5. 切回空白记事本时固定窗口继续可见；文字输入和外部 Right / Left 光标移动成功。一次紧接操作的 Left 截图未变化，重新明确激活后复测列 5→6→5，未据该中间截图认定功能失败。
6. 偏好页显示 Alt+C、Alt+X 与 Ctrl+Shift+V 均已在系统注册。使用自动化工具的多个组合键表示发送 Ctrl+Shift+V，主窗口显示与隐藏时均未取得转换成功；未定位为产品故障或工具输入问题。
