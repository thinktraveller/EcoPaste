# EcoPaste 发布文档

本目录是 `project-docs/` 文档的去敏发布版本，由项目主 Git 仓库追踪。原独立文档仓库的 `.git` 留在原目录，仅用于保留本地历史，不随本目录发布。

## 文档索引

- [project-plan.md](project-plan.md)：快捷键配置、当前剪贴板纯文本转换与窗口固定的历史构建计划。
- [buildlog.md](buildlog.md)：实施、修复、构建和验证记录。
- [验证与验收交接](docs/clipboard-format-desktop-verification.md)：自动检查的证据边界与手工验收方法。

## 去敏范围

本次移除了本机绝对路径、安装位置、私有会话链接、进程编号、精确运行时间及本机构建哈希。源码位置使用项目相对路径，示例产物哈希已替换为占位值。架构、技术契约、修复原因、检查结论和未覆盖范围保留。

这些文件记录开发过程，各日期下的“未实现”“待验收”等文字描述当时状态。后续修复以较新的记录为准；产品最新行为以源码与 `.trellis/` 当前任务契约为准。

私有 Git 历史、本机配置、工具链、运行日志、截图与验证脚本不包含在此目录中。文档中 `_verify/` 引用只说明当时的证据位置，不表示相应文件已经发布；本机环境脚本不能作为通用开发前置条件。

协作规则以根目录 `AGENTS.md` 为准。后续内部工作文档仍按项目规范放在 `project-docs/`，需要发布时再去敏同步至本目录。
